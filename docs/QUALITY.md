# 品質ルールと落とし穴

## 全カード必須
1. 多義語は、よく使う順に意味を並べる（1〜4個）。
2. 各意味に、短く自然な例文1つと英訳。例文はなるべくデッキ内の語彙で作る。
3. 類義語・対義語は自然なものだけ。意味がずれるものは付けない（例：poco a poco に despacio は×）。
4. 例文・チップの全単語が `lookup()` で引けること。引けない語は EXTRA に追加（活用形なら原形も）。
5. 見出し語の重複禁止。単なる女性形・複数形は別見出しにしない（例外：padres など意味が変わる語）。
6. 同根語に `cog:1`、偽の友に `ff`（Toolkit の一覧に自動で出る）。部分的な偽の友も ff を付けてよい（例：discusión, introducir）。
7. 動詞は活用タイプを正しく。エンジンが作れない形は IRR へ。追加後は活用表を目で確認。
8. 実在の人物・固有名詞は例文に多用しない。
9. 他のカードと同じ例文を使わない。

## これまでに見つかった落とし穴（再発防止）
- **複数形・女性形が動詞の活用として引かれる**：baja（bajar）、plantas（plantar）、notas（notar）、hechos（hacer）、fría（freír）など。新しい動詞を追加すると、既存の名詞・形容詞の例文で新たに起きることがある。`--shadow` で確認し、EXTRA に `"baja":["short; low (feminine)","bajo"]` のように追加する。
- **別の見出し語とぶつかる**：lista（list）、cara（face）、chica（girl）、práctica（practice）のように、形容詞の女性形と同じ形の名詞がある場合、EXTRA を足すと名詞の方まで表示順が変わる。**例文を男性形に書き換える**方がよい（例：「Es muy lista」→「Es muy listo」）。
- **派生語の意味を元の語に書かない**：último に「lately（últimamente）」、prueba に「to try on（probarse）」のような意味を入れない。派生語は別カードにする。
- **活用エンジンが苦手なもの**（IRR で補う）：-ger/-gir（coja, elija）、-guir（siga）、-iar/-uar のアクセント（envíe, actúe, continúe）、prohibir（prohíbo）、reunir（reúna）、-ducir の点過去（traduje）、andar（anduve）、reír/freír、不規則な過去分詞（devuelto, frito）、c→z（convenzo）。
- **同根語の動詞**：以前は COGS の処理が語幹変化動詞の活用を規則形で上書きしていた（修正済み）。COGS の pos はデッキと同じにする。
- **IRR のキー重複**：同じ動詞を2回書くと後の方が黙って勝つ。フィールドの追記は add-batch に任せる。
- **フレーズの例文**：フレーズ自体が例文中で認識されないと、EN→ES のヒントの空欄がずれる。check が確認する。
- **CEFR**：B1・B2 は頻度の高い日常語・一般語を優先。専門用語・地域限定の語は避ける。地域限定の表現を入れるときは "Spain, informal" などと明記する。

## データの出典と限界
- 上位約960語は公開の頻度リスト（書き言葉寄り）の順位。それ以外の選定・意味の順序・CEFR は Claude の判断による目安で、公式の語彙表とは照合していない。
- 活用表は自動生成。2026-09 に全動詞を目視確認済み。
