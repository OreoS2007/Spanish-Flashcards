# スペイン語単語帳（Español Core）— はじめに読むファイル

このフォルダには、単語帳アプリと、Claude Code が作業するための説明書・道具が全部入っています。

## 1. フォルダを置く
1. ダウンロードした ZIP ファイルを開く（ダブルクリック）。
2. 出てきた「spanish-flashcards」フォルダを、わかりやすい場所に移す。
   おすすめは「書類（Documents）」フォルダの中です。
3. **このフォルダの名前や中身の場所は変えないでください。**

## 2. Claude Code でフォルダを開く
1. Claude のデスクトップアプリを開き、Code（Claude Code）を選ぶ。
2. 作業するフォルダとして「spanish-flashcards」を選ぶ。
3. Claude Code はフォルダ内の `CLAUDE.md`（説明書）を自動で読み込みます。

## 3. 最初に送るメッセージ（コピーして貼り付け）
```
CLAUDE.md と docs/ フォルダの資料を全部読んで、このプロジェクトの状況を把握して。
そのあと、作業の準備をして（npm install と npx playwright install chromium）、
npm run check と npm test が通るか確認して。
最後に git で履歴管理を始めて、今の状態を最初のコミットにして。
わからない操作があれば、一歩ずつ日本語で教えて。
```
- 途中で「このコマンドを実行してよいか」と聞かれたら、内容を見て許可してください。
- Node.js（道具を動かすためのソフト）が入っていないと言われたら、Claude Code に「Node.js の入れ方を教えて」と頼めば案内してくれます。

## 4. ふだんの頼み方の例
- 「B2 の単語を300語くらい追加して」
- 「フレーズをあと100個追加して。会話でよく使うものを中心に」
- 「◯◯という単語の例文が不自然なので直して」
- 「今の単語数をワールドごとに教えて」

## 5. 公開（スマホで使えるようにする）
作業が終わったら、`docs/DEPLOY.md` の方法で公開します。
- **方法A（今までどおり）**：claude.ai の「スペイン語単語帳」プロジェクトのチャットに `index.html` を添付して、
  「添付の index.html で https://claude.ai/artifact/8fRhEgVQk9GarwHoCeVVu9 を更新して公開して。新しいアーティファクトは作らないで。」と頼む。
- **方法B（慣れてきたら）**：GitHub Pages で自分のサイトとして公開。Claude Code に「GitHub Pages で公開できるように手伝って」と頼めば案内してくれます（URL が変わるので、今の進捗は引き継がれません）。

## 6. 困ったとき
- 何かおかしくなったら：「直前の変更を取り消して」と頼む（git で元に戻せます）。
- 単語を追加すると、`backups/` フォルダに自動で控えが残ります。
